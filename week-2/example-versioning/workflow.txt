# Problem Statement

Machine Learning projects consist of three important components:

* Source Code
* Dataset
* Trained Models

Git is excellent for versioning source code but is not suitable for handling large datasets and model artifacts because these files change frequently and significantly increase repository size.

The objective of this assignment is to integrate **Data Version Control (DVC)** into an ML workflow so that datasets and trained models can be versioned efficiently while using **Google Cloud Storage (GCS)** as remote storage.

This enables reproducible machine learning experiments where previous versions of datasets and models can be restored whenever required.

---

# Objective

The main objectives of this assignment are:

• Understand Data Version Control (DVC)

• Integrate DVC with Git

• Configure Google Cloud Storage as DVC Remote

• Track datasets using DVC

• Track trained models using DVC

• Upload artifacts to Google Cloud Storage

• Create multiple model versions

• Restore previous versions using Git and DVC

# Configure Google Cloud Storage

Google Cloud Storage bucket created:

```text
gs://week-2-mlops-21f3001560
```

Configure DVC Remote:

```bash
dvc remote add -d gcsremote gs://week-2-mlops-21f3001560
```

---

# First Iteration

Download dataset:

```bash
dvc get https://github.com/iterative/dataset-registry tutorials/versioning/data.zip

unzip -q data.zip

rm -f data.zip
```

Track Dataset:

```bash
dvc add data
```

Train Model:

```bash
python train.py
```

Track Model:

```bash
dvc add model.weights.h5
```

Upload Dataset & Model:

```bash
dvc push
```

Commit:

```bash
git add data.dvc model.weights.h5.dvc metrics.csv .gitignore

git commit -m "First iteration with 1000 images"
```

Create Version:

```bash
git tag -a v1.0 -m "Model version 1.0"
```

---

# Verify First Version

Delete Local Cache:

```bash
rm -rf .dvc/cache
```

Restore from Remote:

```bash
dvc pull

dvc checkout
```

Successful verification confirms that Version 1 is safely stored inside Google Cloud Storage.

# Why Git + DVC?

Git tracks

* Source Code
* Documentation
* DVC Metadata

DVC tracks

* Large Datasets
* Trained Models

Google Cloud Storage stores

* Actual Dataset Files
* Actual Model Files

This keeps Git repositories lightweight while maintaining complete experiment reproducibility.
