PROBLEM STATEMENT
=========================================================

The objective of Week-5 is to integrate MLflow into the existing IRIS
Machine Learning pipeline developed in previous assignments.

The pipeline already included:

• Google Vertex AI Workbench
• Feast Feature Store
• Version controlled dataset
• Random Forest model training

In this assignment, MLflow is introduced to provide experiment tracking,
model versioning and model registry support.

The major objectives are:

1. Perform hyperparameter tuning.
2. Log all experiments into MLflow.
3. Compare experiment runs.
4. Register trained models in MLflow Model Registry.
5. Load the registered model directly from MLflow during prediction instead
   of using local model artifacts.
