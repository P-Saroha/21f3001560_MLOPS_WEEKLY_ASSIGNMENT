Problem Statement
-----------------

In Week 2, DVC was used to version datasets and model artifacts.

DVC helps answer the question:

"Which version of the dataset was used for model training?"

However, DVC alone does not solve another important production problem:

"How can we ensure that the exact same feature engineering logic is used during both model training and model inference?"

If training and serving use different feature transformations, the model may receive different inputs during inference, leading to **Training-Serving Skew**.

To solve this problem, Feast Feature Store was integrated into the IRIS machine learning pipeline.

Feast provides a centralized feature repository that allows both training and inference to retrieve the same features from a single source of truth.
