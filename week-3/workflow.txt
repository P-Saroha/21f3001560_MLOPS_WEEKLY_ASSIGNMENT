Problem Statement
-----------------

In Week 2, DVC was used to version datasets and model artifacts.

DVC answers an important question:

"Which version of the dataset was used for model training?"

However, DVC does not solve another important production problem:

"How can we guarantee that exactly the same feature engineering logic is used during both model training and model inference?"

If feature engineering is implemented separately for training and inference, the model may receive different feature values during prediction. This issue is known as Training-Serving Skew.

To eliminate this problem, Feast Feature Store was integrated into the IRIS Machine Learning Pipeline.

Feast provides a centralized feature repository that ensures both Offline Training and Online Inference retrieve the same feature definitions from a single source of truth.

For this assignment, the official IIT Madras Week 3 time-aware IRIS dataset was used.
