16. DATA DRIFT INTERPRETATION
=============================

Data drift occurs when the statistical distribution of model inputs
changes over time.

Formally:

P(X) changes

In this assignment:

petal_length distribution changed.

petal_width distribution changed.

Therefore, significant data drift was detected for those features.

Data drift does not automatically prove that model accuracy has
decreased.

Instead, it is a monitoring signal that should trigger further
model evaluation and potentially retraining.

=================================================================
17. DATA DRIFT VS CONCEPT DRIFT
===============================

DATA DRIFT:

P(X) changes

Example:

The distribution of petal_length in production is different from
the training distribution.

CONCEPT DRIFT:

P(Y | X) changes

Example:

The relationship between IRIS features and species changes over
time.

The current assignment demonstrates DATA DRIFT.

Concept drift requires monitoring the relationship between model
inputs and ground-truth target labels over time.
