MLOps Week 4 Workflow
Continuous Integration for IRIS Pipeline
=========================================================

Student ID
----------
21F3001560

Assignment Goal
---------------

Integrate Continuous Integration into the existing IRIS ML Pipeline using GitHub Actions.

The workflow automatically performs:

1. Pull versioned artifacts using DVC
2. Validate dataset
3. Validate trained model
4. Run prediction tests
5. Generate test report
6. Publish report using CML

=========================================================
Problem Statement
=========================================================

In previous weeks:

Week 1
-------
Built an IRIS Classification Pipeline.

Week 2
-------
Integrated DVC to version datasets and trained models.

Week 3
-------
Integrated Feast Feature Store for consistent feature serving.

Problem:

Every time code changes were pushed to GitHub, there was no automatic verification that:

- dataset remained valid
- model still loaded correctly
- predictions remained correct
- versioned artifacts were available

This could introduce bugs into the project.

Therefore Week 4 introduces Continuous Integration.
