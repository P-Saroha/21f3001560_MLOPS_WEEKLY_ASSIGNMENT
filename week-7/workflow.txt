=========================================================
WEEK 7 WORKFLOW
Stress Testing, Observability & Scaling the IRIS Pipeline
=========================================================

Objective
---------
Validate the deployed IRIS API under high concurrency, configure Kubernetes
Horizontal Pod Autoscaler (HPA), monitor the application using Google Cloud
Monitoring and Cloud Logging, and analyze performance bottlenecks under
constrained scaling.

---------------------------------------------------------
STEP 1: Activate Virtual Environment
---------------------------------------------------------

cd ~/21f3001560_MLOPS_WEEKLY_ASSIGNMENT

source .env/bin/activate

Verify Python:

python --version

---------------------------------------------------------
STEP 2: Verify GCP Configuration
---------------------------------------------------------

Check active project:

gcloud config get-value project

Check authenticated account:

gcloud auth list

List GKE clusters:

gcloud container clusters list

---------------------------------------------------------
STEP 3: Connect to GKE Cluster
---------------------------------------------------------

gcloud container clusters get-credentials iris-cluster \
    --zone us-central1-a \
    --project project-a74bda7f-3a9e-4ff2-a23

Verify nodes:

kubectl get nodes

---------------------------------------------------------
STEP 4: Verify Existing Deployment
---------------------------------------------------------

View Deployments:

kubectl get deployment

View Services:

kubectl get svc

View Running Pods:

kubectl get pods

Describe Deployment:

kubectl describe deployment iris-api

---------------------------------------------------------
STEP 5: Verify API
---------------------------------------------------------

Home Endpoint

curl http://34.44.129.164/

Prediction Endpoint

curl -X POST http://34.44.129.164/predict \
-H "Content-Type: application/json" \
-d '{
  "sepal_length": 5.1,
  "sepal_width": 3.5,
  "petal_length": 1.4,
  "petal_width": 0.2

{
  "prediction":"setosa"
}

---------------------------------------------------------
STEP 6: Deploy Updated Resources
---------------------------------------------------------

Apply Deployment

kubectl apply -f deployment.yaml

Apply Service

kubectl apply -f service.yaml

Verify rollout

kubectl rollout status deployment/iris-api

---------------------------------------------------------
STEP 7: Configure Horizontal Pod Autoscaler
---------------------------------------------------------

Apply HPA

kubectl apply -f hpa.yaml

Verify HPA

kubectl get hpa

Verify Pods

kubectl get pods

---------------------------------------------------------
STEP 8: Stress Testing using wrk
---------------------------------------------------------

Run High-Concurrency Load Test

wrk -t4 -c1000 -d30s -s post.lua http://34.44.129.164/predict

Observe:

- Requests/sec
- Latency
- Socket Errors
- Timeouts

---------------------------------------------------------
STEP 9: Observe Autoscaling
---------------------------------------------------------

Open another terminal

Watch HPA

watch -n1 kubectl get hpa

Open another terminal

Watch Pods

watch -n1 kubectl get pods

Observe:

- Replica count
- CPU utilization
- Pod scaling

---------------------------------------------------------
STEP 12: Bottleneck Analysis
---------------------------------------------------------

Edit hpa.yaml

Change

maxReplicas: 3

to

maxReplicas: 1

Apply

kubectl apply -f hpa.yaml

Verify

kubectl get hpa

Run Stress Test

wrk -t4 -c2000 -d30s -s post.lua http://34.44.129.164/predict

Observe

- Higher latency
- Increased socket timeouts
- Reduced throughput
- Single running pod

---------------------------------------------------------
STEP 13: Compare Results
---------------------------------------------------------

Scenario 1

Connections : 1000

Observe

- Requests/sec
- Latency
- CPU
- Autoscaling

Scenario 2

Connections : 2000

Max Replicas : 1

Observe

- Requests/sec
- Latency

- Performance degradation
