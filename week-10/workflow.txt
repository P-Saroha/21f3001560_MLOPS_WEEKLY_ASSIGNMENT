36. SHORT DEMO EXPLANATION
======================================================================

"This week I extended the existing IRIS MLOps pipeline
into an LLMOps workflow.

I created two representations of the same IRIS dataset.

V1 uses structured numerical feature prompts and V2 uses
natural-language descriptions.

Both representations use exactly the same fixed
train, validation and test split so that the comparison
is fair.

I converted both datasets into Gemini-compatible JSONL
format and uploaded them to Google Cloud Storage.

Then I used Vertex AI supervised fine-tuning with
Gemini 2.5 Flash Lite.

Both models were trained for 3 epochs with adapter size 4.

After successful tuning, I used Vertex AI endpoints to
serve the tuned models.

Finally, I evaluated both models on the same 15-example
test set.

V1 achieved 66.67% accuracy, corresponding to 10 correct
predictions out of 15.

V2 achieved 0% under the implemented evaluation protocol.

Therefore, V1 was the better-performing representation
in this experiment.

I also measured output-format compliance because an LLM
can produce the correct reasoning but still fail a
downstream classification pipeline if the output format
is not controlled."
